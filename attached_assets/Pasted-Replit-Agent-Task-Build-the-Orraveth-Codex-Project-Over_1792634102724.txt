Replit Agent Task: Build the Orraveth Codex

Project Overview

Create a new, standalone web application called The Orraveth Codex, a beautifully designed, navigable fantasy-world encyclopedia documenting the fictional world of Orraveth.

Orraveth is an original, medieval-inspired fantasy setting being developed for a modular multiplayer MUD game engine.

The application should feel like an immersive fantasy encyclopedia, combining the usability of a modern documentation website with the atmosphere of an ancient scholar's archive.

The goal is to create a living worldbuilding knowledge base, not merely a collection of static articles.

The site must be accessible, mobile-first, responsive, easy to navigate, searchable, and designed for long-term expansion.

1. Technology and Architecture

Use the following stack:

- React and TypeScript
- Tailwind CSS v4
- Vite
- React Router for navigation
- Markdown/MDX for lore content
- Zod for content schema validation
- Lucide icons
- A lightweight, maintainable search implementation

Prefer established, well-maintained libraries over custom implementations.

Organize the application into clearly separated components, content, data models, and presentation layers.

Suggested structure:

src/
  components/
    layout/
    navigation/
    wiki/
    search/
    ui/
  pages/
  content/
    world/
    religions/
    magic/
    sprites/
    characters/
    factions/
    locations/
    history/
    items/
    economy/
  lib/
    content/
    search/
  types/
  styles/

The content system must support adding new entries without manually creating routes or navigation links.

Use structured frontmatter or equivalent metadata for every wiki entry.

Do not introduce a database unless it is genuinely necessary. For the initial implementation, Markdown/MDX files should be the primary source of truth.

Design the content layer so that it can eventually integrate with an external API or database.

2. Visual Design

Create a distinctive dark-fantasy aesthetic inspired by ancient manuscripts, medieval libraries, cartography, and scholarly archives.

Avoid generic SaaS dashboard styling.

Design characteristics:

- Warm parchment-inspired backgrounds in light mode
- Deep charcoal, aged bronze, muted forest green, and amber accents
- Elegant serif typography for headings
- Highly legible typography for body content
- Subtle ornamental borders and dividers
- Carefully designed article layouts
- Responsive navigation
- Optional dark mode
- Tasteful animations and transitions
- Atmospheric but restrained visual details

The interface must remain modern and usable.

Avoid excessive textures, animations, or decorative elements that reduce readability.

Core layout

On desktop:

- Left sidebar containing the encyclopedia navigation
- Central article reading area
- Optional right sidebar containing the current article's table of contents
- Breadcrumb navigation
- Global search

On mobile:

- Collapsible navigation
- Full-width reading experience
- Accessible search
- Comfortable touch targets
- Responsive tables and media
- No horizontal overflow

Search

Implement full-text search across article titles, descriptions, tags, and content.

Cross-references

Articles should automatically link to related entries where relationships are defined.

For example:

Professor Elira Venn → Glass Collegium → Resonance → Sprite Essence → Unbinding Initiative.

Canon status

Every article must be marked as one of:

- Established Canon: A worldbuilding fact accepted as true.
- Provisional Canon: An established direction that may change.
- In-World Belief: A claim held by a religion, culture, character, or institution.
- Disputed: An issue with competing explanations.
- Unresolved: A mystery intentionally left unanswered.

This distinction is essential.

Do not present religious claims, rumors, hypotheses, or character opinions as objective facts.

An article may contain multiple claims with different epistemic statuses.

4. World Lore: Orraveth

Populate the encyclopedia with substantial, interconnected articles based on the following worldbuilding material.

Preserve the established names, themes, and relationships.

Where details have not been established, expand creatively but mark additions as provisional.

Do not resolve intentional mysteries.

The world

Orraveth is the main continent and setting.

Its inhabitants live in a physically real universe containing planets, stars, and other astronomical phenomena, but possess a medieval level of cosmological knowledge.

Different cultures and religions disagree about the universe's origin.

Magic, sprites, and powerful entities regarded as gods demonstrably exist.

However, their existence does not establish that any particular religion or creation story is correct.

The world is entering an Age of Measures, in which natural philosophers are increasingly applying empirical methods to the study of magic and the physical universe.

Scientific progress creates political, economic, and theological tensions.

Avoid simplistic divisions between science and religion. Religious institutions contain reformers and scholars, while scientific institutions contain rivalries, biases, and political interests.

Religions and creation stories

Create detailed articles for four major traditions, including their competing internal branches.

The Lantern Covenant

Creation story: Auren lit the First Lantern from its own essence, bringing light and existence into being.

Branches:

- Keepers of the Single Flame: Auren remains conscious and governs creation.
- Open Lanterns: Auren expended itself in creation, leaving mortals responsible for the world.

The Sevenfold Workshop

Creation story: Seven divine artisans shaped an unfinished universe, each contributing different aspects of existence.

Branches:

- True Pattern: Creation has an intended order that should be respected.
- Living Forge: Mortals should continue and improve the work of creation.

The Returning Tide

Creation story: Reality passes through recurring cycles of creation and dissolution. Namar, the Remembering One, persists across cycles.

Branches:

- Stillwater Orders: Accept impermanence and the natural cycles of existence.
- High-Tide Pilgrims: Preserve knowledge and civilization across cycles.

The Rootless Way

Worldview: Existence emerged through natural processes without requiring an intentional creator. Gods and sprites may themselves be emergent beings.

Branches:

- Green Branch: Nature and conscious landscapes deserve reverence and protection.
- Clear Branch: Natural philosophy and skeptical inquiry are preferable to worship.

Include theology, practices, social influence, internal disagreements, historical conflicts, and views on sprites and magic.

These religions must not be treated as uniformly good or evil.

Magic and Resonance

Magic is a mechanically consistent phenomenon commonly called Resonance.

Its ultimate origin remains unknown.

Five practical laws:

1. Magical effects require patterns.
2. Change requires energy or resources.
3. Range, mass, duration, complexity, and resistance constrain effects.
4. Lasting enchantments require stable anchors.
5. Known magic transforms existing matter and energy rather than freely creating unlimited resources.

Five recognized disciplines:

- Kindling: Energy and elemental effects.
- Shaping: Manipulation of physical matter.
- Veiling: Perception and illusion.
- Binding: Connections, wards, and magical anchors.
- Listening: Detection, communication, and interactions with sprites.

Create separate articles for the system, laws, and disciplines.

Distinguish observed magical behavior from competing explanations of why magic exists.

Sprites

Sprites are supernatural entities with varying degrees of consciousness, agency, and physical influence.

They can exist independently or become anchored to objects, buildings, locations, or living beings.

Operational classifications:

- Dormant
- Whispering
- Manifesting
- Embodied
- Sovereign

Anchoring can be accidental, voluntary, or forced.

Sprites may communicate, remember, form relationships, resist commands, and possess individual personalities.

Their origin and metaphysical nature remain disputed.

Create articles about sprite classification, anchoring, consent, personhood, legal status, and cultural beliefs.

Include the following examples:

- The Sword Called Mercy: A sword inhabited by a sprite that refuses to harm unarmed people.
- The House That Waits: A sentient building that sometimes confines visitors out of fear of abandonment.
- The Widow of the River: A mysterious river sprite associated with grief and flood warnings.
- Hearth: An intelligent sprite inhabiting the Kindly Roof Inn.

Sprite essence and alchemy

Introduce Veyl, a concentrated substance associated with sprites and used in many magical potions.

Veyl can power alchemical reactions, including accelerated healing.

Its exact relationship to sprite consciousness, identity, and memory is not fully understood.

Harvesting methods include:

1. Ambient collection
2. Voluntary offering
3. Cultivated extraction
4. Destructive extraction

Some sprites can safely release excess essence. Other harvesting practices can cause serious harm.

Repeated or destructive extraction may damage memory, personality, agency, or the ability to manifest.

Do not portray all essence harvesting as inherently harmful or harmless.

The ethics depend on consent, circumstances, consequences, and the sprite involved.

Create interconnected articles about:

- Veyl
- Healing potions
- Essence harvesting
- Ethical controversies
- Alchemical production
- Alternative medicine
- Sprite personhood
- Essence provenance
- The Hollowing

The Unbinding Initiative

A collaborative research movement seeking alternatives to essence-based magical medicine.

Its major schools are:

Botanical School: Investigates plants and minerals capable of replicating magical healing.

Resonance Engineers: Seek artificial or alternative sources of magical energy.

Symbiotic School: Develops cooperative healing methods that do not require extracting sprite essence.

These approaches have different philosophical assumptions and technical limitations.

Essence-free healing is possible experimentally, but remains expensive and difficult to scale.

Master Alchemist Severin Vale

Severin Vale is a wealthy industrialist and master alchemist who has developed an exceptionally efficient but destructive essence-extraction process.

He calls it Refinement.

Critics call it the Hollowing.

The process can strip sprites of their memories, agency, and coherent identities.

Severin operates legitimate medical businesses and hospitals while secretly exploiting sprites.

His daughter Mara suffers from a degenerative illness requiring ongoing treatment.

His actions began with attempts to save her life but developed into a profitable industrial system.

Severin argues that ordinary society hypocritically condemns his methods while depending on the essence-harvesting industry.

Present him as an intellectually serious antagonist whose criticism contains legitimate observations, but whose methods and conclusions remain morally contestable.

The Glass Collegium

A major scholarly institution associated with the Age of Measures.

Its researchers investigate Resonance, sprites, alchemy, astronomy, and natural philosophy.

The institution contains competing schools of thought and is influenced by funding, politics, and academic rivalries.

Professor Elira Venn

A 43-year-old natural philosopher specializing in Resonance measurement and incorporeal sprites.

Elira is skeptical, methodical, and interested in developing instruments capable of measuring sprite activity.

Her research suggests that repeated essence extraction may damage sprite identity.

She has recently disappeared near Bellwold while investigating the village's mysterious bell.

Create an article about her research and disappearance.

Nations and regions

Create articles for:

Crown of Heskar: Hereditary monarchy with strong property laws, rigid borders, and expansionist frontier interests.

Merefall League: Merchant city-state league dominated by guilds and commercial interests.

Veyrun Concord: Religiously influential federation balancing temple and civic authority.

Sareth Cantons: Mountain communities with local assemblies, universities, mining interests, and skilled craftsmanship.

Rillward Freeholds: River settlements and mobile communities governed through negotiated councils and reciprocal rights.

The Uncrowned Lands: Regions beyond centralized national control, also called the Wild, Open Marches, Old Ground, Free Soil, or Breathing Lands depending on the speaker.

These territories are not necessarily uninhabited or available for settlement.

Include independent peoples, communities, ruins, and sprite territories.

Bellwold

Bellwold is a small trading village near the frontier of Heskar.

Its economy includes farming, milling, blacksmithing, trade, lodging, and small-scale crafting.

Important locations:

- The Kindly Roof Inn
- Marr's General Goods
- Blackwater Forge
- The Green Mortar
- Bellwold Market Square
- The old bell tower
- The eastern forest
- The abandoned watermill

Important characters:

Tomas: Innkeeper of the Kindly Roof.

Anwen Marr: 56-year-old merchant operating Marr's General Goods.

Darric Holt: Blacksmith at Blackwater Forge.

Ilya Fen: Village healer associated with the Green Mortar.

Jorek Vass: Traveling merchant who visits Bellwold periodically.

Professor Elira Venn: Missing scholar.

Create detailed, interconnected location and character articles.

Bellwold mysteries

The Silent Bell

Bellwold's old bell has historically rung before storms.

After Elira Venn began measuring its Resonance, the bell stopped ringing.

Historical records suggest that it once rang continuously during a period when seventeen villagers disappeared.

The bell originally came from the eastern forest.

Its true nature remains unresolved.

The Forgotten Journal

Elira's journal was discovered in the Kindly Roof.

Its final entries describe unusual measurements, missing historical records, and a mysterious voice.

Hearth, the inn's resident sprite, placed the journal where someone could find it.

The Mill That Never Sleeps

An abandoned watermill continues operating despite being deserted.

An agent connected to Severin Vale is secretly using its resident sprite in an extraction apparatus.

The resulting essence is entering the regional healing-potion supply chain.

Anwen's Balance Scale

Anwen Marr owns an unusual scale that sometimes produces impossible measurements.

A weak sprite may be anchored to it.

Its exact abilities are unknown.

6. Knowledge and Narrative Design

This encyclopedia must distinguish between:

Objective world facts: Information established by the worldbuilding authors.

In-world knowledge: Information known or believed by fictional people.

Rumors and hypotheses: Claims that may be inaccurate, incomplete, or intentionally misleading.

Unresolved mysteries: Questions whose answers have not yet been established.

For example:

A character may believe that sprites are fragments of divine consciousness.

The encyclopedia should document that belief without asserting it as objective truth.

A scholar may believe Veyl extraction damages memory.

The encyclopedia should distinguish their evidence from what is conclusively established.

Where useful, include sections such as:

- What Is Known
- Competing Theories
- Historical Accounts
- Cultural Interpretations
- Related Mysteries

7. Future MUD Engine Integration

Although this application is initially a standalone wiki, design its data structures for eventual integration with a modular game engine.

Every major entity should have a stable identifier.

Support relationships between entities such as:

- Character → Faction
- Character → Location
- Location → Region
- Item → Crafting Material
- Religion → Branch
- Sprite → Anchor
- Potion → Ingredient
- Organization → Member
- Event → Location
- Research → Discovery

Define typed schemas that could later map to an API or relational database.

Do not implement the actual MUD engine in this project.

The wiki is a separate application.

It should eventually be possible to use its structured content to help populate the game world.

8. Essential Pages

Create at least the following functional pages:

1. Home: Atmospheric landing page introducing Orraveth, featured articles, major topics, and mysteries.
2. Explore: Browsable encyclopedia categories.
3. Article: Reusable template for individual wiki entries.
4. Search: Searchable index of articles.
5. Timeline: Chronological presentation of important historical events.
6. World Atlas: A region directory with navigation to individual places.
7. Relationships: A way to discover connected people, organizations, locations, and concepts.

For the World Atlas, begin with a clean, navigable region directory. Do not invent precise geographical coordinates or borders that have not been established.

A graphical map may be added later.

9. Content Quality

Write substantial articles with a consistent editorial voice.

The tone should resemble a serious fantasy encyclopedia rather than promotional marketing copy.

Content should be immersive, precise, and thoughtful.

Prefer concrete details and meaningful relationships over vague descriptions.

Use cross-links frequently.

Avoid presenting every mystery as something that must be solved.

Orraveth should feel like a world where ordinary people live independent lives, not a theme park built solely for adventurers.

10. Implementation Process

Work in phases.

Phase 1 — Foundation

Establish the project, architecture, routing, design system, content schemas, and basic layouts.

Phase 2 — Encyclopedia

Implement article rendering, categories, internal links, search, tags, and related content.

Phase 3 — World Content

Populate the site with the supplied Orraveth lore and supporting articles.

Phase 4 — Exploration

Implement the timeline, atlas directory, relationships, and discovery features.

Phase 5 — Quality Assurance

Verify mobile responsiveness, accessibility, navigation, search, content consistency, and build correctness.

11. Acceptance Criteria

The project is complete when:

- The application runs successfully in Replit.
- The site is fully responsive and mobile-first.
- The encyclopedia contains substantial interconnected lore.
- Every major person, place, organization, religion, and magical concept described above has an appropriate entry.
- Search works across the content.
- Navigation and breadcrumbs work.
- Related-article links work.
- Timeline and atlas pages are functional.
- Canon status is visible and accurately represented.
- The application is accessible by keyboard.
- The content architecture supports easy expansion.
- TypeScript checks and production builds succeed.
- No broken internal links remain.
- The project includes a README explaining architecture, content authoring, and future integration.

12. Important Instructions

Before implementation, inspect the existing Replit project and determine whether there is any code worth preserving.

If the project is empty, scaffold the application.

Make reasonable implementation decisions autonomously.

Ask for clarification only when a decision would materially affect the architecture or contradict the established lore.

Do not replace the original setting with established Dungeons & Dragons intellectual property or copyrighted fantasy settings.

Do not invent definitive answers to intentionally unresolved mysteries.

Preserve the philosophical ambiguity surrounding gods, sprites, creation, consciousness, and magic.

Prioritize a polished, functional encyclopedia with excellent navigation and internally consistent content over unnecessary technical complexity.

The final product should feel like opening a living historical archive of a world that existed long before the reader arrived.
