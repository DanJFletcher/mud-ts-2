# Reference sources and editorial basis

These resources inform how the skill organizes and maintains a wiki; **they do not establish MUDD's fictional canon**.

- Replit Agent Skills: https://docs.replit.com/replitai/skills — persistent project skills in `.agents/skills`, on-demand skill loading.
- World Anvil worldbuilding wiki: https://www.worldanvil.com/features/worldbuilding-wiki — interconnected world articles, discoverability, categories and author-controlled visibility.
- MediaWiki categories: https://www.mediawiki.org/wiki/Help:Categories — category navigation and browseable indexing.
- MediaWiki redirects: https://www.mediawiki.org/wiki/Help:Redirects — identity, alternate names, renamed pages, broken references.
- Obsidian links: https://obsidian.md/help/links — wikilinks and portable Markdown links; choose one per repository.
- Obsidian properties: https://obsidian.md/help/properties — human-readable YAML metadata with limited field types.
- Docusaurus Markdown links: https://docusaurus.io/docs/markdown-features/links — relative Markdown links in sites built from docs.
- Docusaurus sidebar: https://docusaurus.io/docs/sidebar — docs navigation; do not create UI build code while invoking this skill.

Sources of actual lore must come from explicit user statements, approved world text or the project's existing documentation. Real-world research may provide analogies for geography, agriculture or cultural history when authorized, but can never on its own canonize a setting fact. Avoid copying third-party fictional settings without permission.
