# Puzzle families — choose by cognitive experience, not prop aesthetics

Each family should work in a room-description and inspect/action loop; do not assume graphical affordances. Hybrid puzzles often feel richer than pure riddles.

| Family | Aha / primary activity | Strong implementations | Common pitfalls |
| --- | --- | --- | --- |
| Observation | Notice a discrepancy or regularity | Physical traces, shifting inscriptions, worn levers | Invisible interactables, pixel hunting |
| Deduction / logic | Infer from provided statements | Symbol positions, witness contradictions, order constraints | Missing premises, off-screen knowledge |
| Sequence / mechanism | Understand causal rules and ordering | Windwheel, gears, pressure vents, steam routing | Arbitrary correct sequence, no feedback |
| Spatial / navigation | Construct a mental map and use paths | Room topology, non-Euclidean but consistent landmarks | Undescribed exits, mandatory visual grids |
| Environmental / physics | Apply predictable world properties | Heat, weight, echoes, water pressure, shadow geometry | Rules inconsistent across similar objects |
| Language / inscriptions | Decode a contextual relationship | In-world translation keys, word order, repeated motifs | Real-language fluency or external trivia gate |
| Social / testimony | Cross-check motives and partial knowledge | Two unreliable but consistent witnesses, schedule clues | Requiring one charisma roll to obtain all facts |
| Cooperative / asymmetric info | Combine observations held by different roles | Each player sees a distinct ledger, complementary controls | Simultaneous timing mandate, single-player hardlock |
| Resource / optimization | Plan among scarce, visible options | Reusable tokens, limited fuel with recoverable failure | Hidden budget, irreversible resource trap |
| Meta / systemic | Apply learned world rules unexpectedly | A familiar symbol meaning changes with orientation | Surprise rules, out-of-genre arbitrary twist |
| Mystery / forensic | Infer why an event occurred | Physical timeline, corroborating records, contradictions | One missing clue blocks all progress |
| Ritual / cultural | Decode purpose from world history | Customs enacted through publicly discoverable rules | Exoticized culture, nonsensical magic passwords |

## Variation framework

Generate puzzles using **place + underlying system + contradiction + observable rule + alternate approach + consequence**, not “invent five riddles.” Example: a floodgate built by water engineers (place/purpose) routes pressure between channels (system); water is present where it should be absent (contradiction); runes label current direction (observable rule); players may equalize pressure or locate an access hatch (alternative); the result affects water level and exposes another passage (consequence).

## What to avoid

- Mandatory guessing of a password with no discoverable derivation.
- A solution requiring the precise phrase in designer notes, rejecting equivalent player intent.
- Pure outside pop-culture, Earth mythology, modern chemistry or obscure linguistic trivia unless taught in the fiction.
- A puzzle that needs a specific D&D spell/class/item no available character can obtain.
- One player with privileged real-world expertise solving everything while others can only wait.
- Visual-only rotating-tile widgets unavailable to a screen reader or TTY.
- Punishing random lever pulling without first showing the relationship between levers and outcomes.
- Apparent branching when only one answer produces any meaningful change.

## Roleplay adaptation

Tabletop/D&D: the GM may adjudicate unforeseen clever solutions consistent with established fictional properties; ability checks can reveal hints or speed execution rather than replacing player choices. Digital MUDD: enumerate and test supported actions, offer synonyms, and record unsupported but plausible approaches as integration gaps; do not hallucinate that any natural-language improvisation can be executed.
