MUDD is a game engine and framework, not a single game. Its original vision is a modular, extensible multiplayer engine inspired by text MUDs, supporting different games through independent plugins. The five pillars are plugin-first architecture, client independence, persistent multiplayer worlds, a developer/modding ecosystem, and flexible hosting and game rules. The ultimate goal is a foundation for living, persistent virtual worlds shaped by players, developers and communities, without constraint to one UI, ruleset or game design.

**Why:** The user provided this as the original product vision; roadmap decisions should evaluate general engine capabilities against it rather than assume the project is only a hosted game.

**How to apply:** When prioritizing architecture work, distinguish foundational capabilities required by this vision from later implementation milestones; do not dismiss the engine, modding, client, hosting, or ruleset goals as unrelated scope.
