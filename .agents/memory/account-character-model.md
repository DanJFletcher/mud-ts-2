---
name: Account and character sessions
description: Product rule for account character rosters and in-world sessions.
---

An account can manage multiple characters, but a world session can play as only one character at a time. Guest players can enter without Clerk sign-in using a browser-held session; signing up in that browser claims the guest identity and its characters.

**Why:** The user clarified that multi-character support belongs to account-level management, then asked for world entry without sign-in. Guest play must not change the one-character-per-world-session rule.

**How to apply:** Keep account identity, guest session, character roster, and the one active character in a world session as separate concepts. Keep guest recovery and account claiming tied to the same browser session.
