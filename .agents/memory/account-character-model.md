---
name: Account and character sessions
description: Product rule for account character rosters and in-world sessions.
---

An account can manage multiple characters, but a world session can play as only one character at a time.

**Why:** The user clarified that multi-character support belongs to account-level management, not concurrent or multi-character gameplay within a world session.

**How to apply:** Keep account identity, character roster, and the one active character in a world session as separate concepts.
