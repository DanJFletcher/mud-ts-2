- [Client design priorities](client-design.md) — Mobile-first gameplay without marketing filler; Traveler info and Field notes belong on separate navigable screens.
- [Account and character sessions](account-character-model.md) — Accounts can manage multiple characters; each world session plays as one character at a time.
- [Puzzle-master skill source](puzzle-master-skill-source.md) — If local skill search misses it, inspect the nested Git bundle read-only rather than restoring deleted skill files.
- [Cross-package error identity](workspace-package-error-identity.md) — Workspace source/dist resolution can create multiple class constructors; use stable error discriminants across package boundaries.
- [Replit preview origins](replit-preview-origins.md) — Preview browser Origins can include `:5000`; allow only exact development hosts and ports.
- [Character-owned combat state](combat-gear.md) — Attributes, gear, health, honors, consumables, and advancement are character-owned; derived combat ratings stay server-side.
- [Consent-based PvP](consent-based-pvp.md) — Player combat requires an explicit challenge acceptance; shared encounter state must not own durable character health or inventory.
- [Quest-bound items](quest-item-binding.md) — Quest-critical items must remain undroppable and unavailable to any future trade or transfer.
- [Map visibility](map-visibility.md) — Show only the current area's floor; preserve exploration when switching between overworld and dungeon maps.
- [Water travel](water-travel.md) — Link river nodes by exits; bridge context is per character and does not change map Z; land entry requires a boat.
- [Party aggregate ownership](party-aggregate-ownership.md) — Keep group membership, encounter teams, party quest state, and durable character state in separate aggregates; see ADR 0014.
- [World-pack authoring types](world-pack-authoring-types.md) — Author against Zod input types when defaults normalize content; keep runtime pack types fully parsed.
- [Orraveth Codex separation](orraveth-codex.md) — Keep Orraveth separate from the MUDD demo; Bellwold is expanding and gold remains provisional.
- [Engine integration tests](engine-integration-tests.md) — Exercise content through a complete, authorized engine host; schema-only tests miss runtime plugin dependencies.
- [World runtime capabilities](world-runtime-capabilities.md) — Treat currency as optional per world, and register shared effect handlers in every runtime that emits those effects.
- [Shared corpses and loot](shared-corpses.md) — Dynamic PvE corpses and their unclaimed loot belong to the shared world-item stream.
- [Room narration](room-narration.md) — Look descriptions use one or two senses; background knowledge belongs in readable sources and NPC dialogue.
- [Deployment packaging](deployment-packaging.md) — Successful builds can still omit runtime dependencies/output; deployment exclusions must differ from Git exclusions.
