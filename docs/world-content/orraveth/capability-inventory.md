This inventory reflects the checked-in contracts, plugins, client SDK, and server registry. “Available” means the capability is exercised through a real engine command or query, not merely described in content.

## Verification coverage

`apps/server/src/orraveth-world.integration.test.ts` validates the pack graph and checks that all 79 locations are reachable, that map coordinates match cardinal exits, and that no two rooms share a tile in the same map area and level. It also checks that concealed canon stays out of the pack's player-facing text and that the `bellwold` settlement group covers the village rooms. It then exercises road travel and encounters, woodcutting, fishing, crafting, room description, autonomous NPC movement and projection, dialogue with residents, quest acceptance, readable-object interaction, quest turn-in, and event replay.

## Architectural limits

The world package is a versioned TypeScript content pack consumed by the server registry. There is no public admin publishing workflow in this repository. Adding dynamic authoring, relationships, or new world-state mechanics requires an explicit engine contract and authorization design; content must not bypass those boundaries with direct database mutation.
